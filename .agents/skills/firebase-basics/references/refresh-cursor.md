# Refresh Cursor

If Firebase skills or the Firebase MCP server need to be refreshed in Cursor, repeat the setup checks in [setup-cursor.md](setup-cursor.md).

1. Re-run the skills installation checks.
2. Re-check the Firebase MCP server configuration.
3. Restart Cursor and confirm the Firebase MCP server is connected.

If you need the full installation and configuration steps, see [setup-cursor.md](setup-cursor.md).
